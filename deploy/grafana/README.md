# Grafana dashboards (ASA Observability)

Generated by `gen_dashboards.py` (`python3 gen_dashboards.py .`). Import each JSON into a folder of your choice;
the `ds` variable selects the Prometheus datasource (default uid `prometheus`).

Metric pipeline assumed: pods expose `/metrics` (port name `metrics`, label `asa.obs/scrape=true`) → OTel Collector
(prometheus receiver + kubeletstats + k8s_cluster + spanmetrics/servicegraph connectors) → Prometheus, with series
labelled `job="asa_obs"` and `asa_cluster=<cluster>`; non-`astro_` metrics are prefixed `asa_`.

| Dashboard | Content |
|---|---|
| `asa-overview` | call volume, error rate, p95, in-flight, HTTP codes, CPU/RAM by namespace |
| `asa-mcp-tools` | per-tool table, rate / p95 / heatmap / errors by tool, transport, sizes, fetch/OSS |
| `asa-resources` | pod/container memory & CPU vs requests/limits, restarts, nodes, collector self-metrics |
| `asa-traces` | span metrics (RED by operation) and service graph; raw traces in Tempo |
| `asa-agent-llm` | placeholders for GenAI token usage and workflow/step durations (needs agent-side instrumentation) |
